COMBAT RESULTS TABLE
AE All attacking units eliminated.
A1 One attacking unit eliminated, attacker choice; attacker retreats any remaining units 1-2 hexes.
AR Attacker retreats all attacking units 1-2 hexes.
C Contact;no loss nor retreats.
EX Both sides eliminate one unit, their choice; attacker retreats any remaining units 1-2 hexes.
DR Attacker retreats all defending units 2 hexes.
D1 One defending unit eliminated, defender choice; attacker retreats any remaining units 1-2 hexes.
DE All defending units eliminated.
DS All defending units surrender. Not replaceable.
